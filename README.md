# 极简物品

一个记录你身边物品的应用

基于 `weapp-vite` + `weapp-tailwindcss` + `tdesign` 的小程序模板开发

## 使用方式

### 开发

- `pnpm dev`

- `pnpm dev --open` 可以打包并直接启动微信开发者工具

### 构建

`pnpm build`

### 打开微信开发者工具

`pnpm open`

### 生成组件/页面

`pnpm g path/to/your/component`
